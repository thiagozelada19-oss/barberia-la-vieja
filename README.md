# Barbería La Vieja — Registro de cortes

App web simple para registrar cortes, cobros (efectivo / Mercado Pago), estadísticas, objetivos y pagos por barbero.

Corre 100% en el navegador (no necesita servidor ni base de datos): los datos quedan guardados en el navegador del dispositivo donde se usa.

## Cómo usarla

Una vez publicada con GitHub Pages (ver más abajo), simplemente abrí el link desde:
- **iPhone**: Safari → tocar el ícono de compartir → "Agregar a pantalla de inicio", para que quede como un ícono de app.
- **Windows**: abrir el link en cualquier navegador (Chrome, Edge).

## Cómo actualizar la app

1. Entrá al repositorio en GitHub.
2. Abrí el archivo `index.html`.
3. Tocá el ícono de lápiz (✏️) para editar, o "Add file → Upload files" para reemplazarlo por una versión nueva.
4. Confirmá los cambios ("Commit changes").
5. Esperá uno o dos minutos — GitHub Pages se actualiza solo.

## Nota

Por ahora, los datos cargados (cortes, barberos, precios, etc.) se guardan por separado en cada dispositivo/navegador — no se sincronizan automáticamente entre el celular y la computadora. Para eso está pensada una futura mejora con inicio de sesión.
